본 개인정보 처리방침은 신민철(이하 "서비스 제공자")이 만든 Tezcatl 모바일 애플리케이션(이하 "앱")에 적용됩니다. 앱은 있는 그대로 제공됩니다.

정보의 수집과 이용

앱은 계정이 필요하지 않으며, 이름·전화번호·주소·정확한 위치를 요구하지 않습니다.

앱에는 Google Analytics for Firebase 와 Firebase Crashlytics 가 포함되어 있습니다. 기기와 Firebase 설정에 따라 다음과 같은 정보가 자동으로 처리될 수 있습니다.

  • 앱 상호작용 및 기능 사용 기록
  • 비정상 종료 로그와 진단 정보
  • 기기 모델, 운영체제 버전, 앱 버전, 언어 등 일반적인 기술 정보
  • 분석과 진단에 사용되는 기기 또는 앱 인스턴스 식별자

이 정보는 앱 사용 현황을 파악하고 오류를 진단하며 안정성과 성능을 개선하는 데 사용됩니다. 서비스 제공자는 이 정보를 광고에 사용하거나 제3자에게 판매하지 않습니다.

앱은 r2tezcatl.groovin.io 에서 TLS 인증서를 내려받을 수 있습니다. 미러링을 시작할 때 저장된 인증서가 없거나 만료가 가까운 경우, 그리고 설정의 인증서 항목에서 업데이트를 누른 경우에 내려받습니다. 호스팅 제공자는 IP 주소, 요청 시각, 사용자 에이전트 등 일반적인 접속 정보를 서버 로그로 처리할 수 있습니다.

앱은 정확한 위치 정보를 수집하지 않습니다. 사용자의 데이터를 처리하거나 기능을 제공하기 위해 인공지능 기술을 사용하지 않습니다.

로컬 화면 미러링과 원격 터치

미러링을 시작하면 화면 영상은 사용자의 Android 기기에서 같은 로컬 네트워크의 브라우저로 직접 전송됩니다. 화면 영상은 서비스 제공자의 서버를 거치거나 그곳에 저장되지 않습니다.

미러링이 동작하는 동안에는 같은 로컬 네트워크에 연결된 기기가 별도의 사용자 인증 없이 표시된 접속 주소로 접근할 수 있습니다. 신뢰할 수 있는 개인 네트워크에서만 사용하고, 필요하지 않을 때는 미러링을 중지해야 합니다.

원격 터치를 켜면 앱은 연결된 브라우저에서 보낸 터치 좌표와 제어 명령을 로컬 네트워크로 받아, 요청된 동작을 수행하는 데에만 사용합니다. 이 입력은 저장되지 않으며 서비스 제공자나 제3자에게 전송되지 않습니다.

접근성 서비스 API

원격 터치는 사용자가 연결된 브라우저에서 요청한 동작을 수행하기 위해서만 Android 의 접근성 서비스 API 를 사용합니다. 이 접근성 서비스는 창의 내용을 가져오지 않도록 설정되어 있으며, 앱은 이를 통해 화면의 텍스트, 비밀번호, 접근성 이벤트를 읽거나 수집·저장·공유하지 않습니다.

이 서비스는 Android 접근성 설정에서 언제든 켜고 끌 수 있습니다. 꺼져 있으면 원격 터치는 동작하지 않습니다.

고정 로컬 주소

지원되는 기기에서 선택 기능인 고정 주소를 켜면, 함께 제공되는 로컬 헬퍼가 Android 의 TestNetworkManager 를 사용해 고정된 로컬 주소를 만듭니다. 같은 로컬 네트워크의 브라우저는 그 주소에 해당하는 도메인으로 앱에 직접 연결할 수 있습니다.

이 기능은 VpnService 를 사용하지 않고, 원격 VPN 서버에 연결하지 않으며, 다른 앱의 트래픽을 검사하거나 전달하지 않습니다. 이 주소 인터페이스를 통해 수집하거나 공유하는 데이터는 없습니다. 인터페이스는 미러링이 끝나거나 헬퍼 연결이 닫힐 때 해제됩니다. 이 기능이 꺼져 있거나 사용할 수 없는 기기에서는 기기의 현재 핫스팟 IP 주소로 접속할 수 있습니다.

무선 디버깅과 로컬 ADB 신원

선택 기능인 가상 디스플레이 모드와 고정 주소를 쓰려면, 사용자가 직접 Android 개발자 옵션을 켜고 무선 디버깅 페어링을 진행해 함께 제공되는 로컬 헬퍼를 준비해야 합니다. 헬퍼는 가상 디스플레이를 만들고 제어하며, 요청이 있을 때 고정 로컬 주소를 유지합니다. 휴대전화를 다시 시작하면 준비 과정이 한 번 더 필요합니다.

앱은 개발자 옵션의 USB 디버깅도 켜도록 안내합니다. Android 는 USB 디버깅과 무선 디버깅이 모두 꺼지면 디버깅 데몬을 종료하는데, 그러면 Wi-Fi 를 벗어나는 순간 헬퍼도 함께 종료되기 때문입니다. 앱은 이 스위치들이 켜져 있는지 읽기만 하며, 값을 바꾸지 않고 사용자를 대신해 어떤 컴퓨터에도 연결하지 않습니다.

ADB 개인키와 인증서는 앱의 비공개 기기 저장소에서 생성·보관됩니다. Android 클라우드 백업과 기기 간 전송에서 제외되며, 서비스 제공자에게 전송되지 않습니다. 페어링은 Android 무선 디버깅 설정에서 해제하거나 앱에서 초기화할 수 있습니다.

헬퍼 실행 파일은 앱에 포함되어 배포됩니다. 앱은 서비스 제공자나 외부에서 실행 코드를 내려받지 않습니다.

선택적 알림 접근

Android 설정에서 알림 접근을 허용하면, 앱은 가상 디스플레이에 알림 패널과 앱 아이콘 뱃지를 보여 주기 위해 현재 알림을 읽습니다. 항목을 누르면 Android 에 해당 알림의 기존 동작을 실행하도록 요청하고, 항목을 지우면 Android 의 알림 리스너 API 를 통해 그 알림을 삭제합니다.

알림의 제목, 내용, 앱 정보, 동작은 기기의 휘발성 메모리에서만 처리됩니다. 앱은 알림 내용을 업로드하거나 저장하지 않고, 판매하거나 공유하지 않습니다. 접근 권한은 Android 알림 접근 설정에서 언제든 해제할 수 있으며, 허용하지 않아도 미러링은 그대로 동작합니다.

기기에 저장되는 정보

앱은 설정값, 온보딩 및 약관 동의 상태, 선택한 블루투스 기기 정보, 런처 구성 등 환경설정을 앱의 비공개 저장소에 보관합니다. 선택한 런처 배경화면은 기기 안의 Android 콘텐츠 참조로만 남으며 앱이 업로드하지 않습니다.

로컬 ADB 신원, 내려받은 TLS 인증서 캐시, 화면 복원을 위한 임시 상태 등 기기별 민감 정보는 Android 백업과 기기 간 전송에서 제외됩니다.

제3자 서비스

앱은 각자의 개인정보 처리방침에 따라 데이터를 처리할 수 있는 제3자 서비스를 사용합니다.

  • Google Play 서비스
  • Google Analytics for Firebase
  • Firebase Crashlytics

서비스 제공자는 법령에 따라 요구되는 경우, 적법한 절차에 응하기 위해, 이용자나 타인의 권리와 안전을 보호하기 위해, 또는 적절한 의무를 부담하는 수탁 서비스 제공자에게 정보를 제공할 수 있습니다.

거부할 수 있는 권리

앱을 삭제하면 Firebase 관련 처리를 비롯한 앱의 데이터 처리를 중단할 수 있습니다. 미러링을 중지하면 화면과 터치 전송을 언제든 멈출 수 있습니다. 알림 접근, 접근성 서비스, 고정 주소 기능, 블루투스 자동 시작, 무선 디버깅은 앱이나 Android 설정에서 끌 수 있습니다.
